# TPOTN Image Guide

Every image slot the site currently expects, with the exact filename and folder it needs. Drop a correctly-named file into the matching folder under `public/assets/images/` and refresh — no code changes needed.

If a file is missing, that slot just falls back to the current gradient + icon placeholder — nothing breaks.

**Recommended:** JPG, landscape orientation, at least 1200×900px for hero images and 800×600px for card images, optimized for web (under ~300KB each).
